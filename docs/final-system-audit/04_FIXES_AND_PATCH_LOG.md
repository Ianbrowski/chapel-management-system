# 04 — Fixes & Patch Log

Every confirmed defect identified during the Final System-Wide Audit was patched in-place cleanly without breaking existing routes or schema contracts. All edits were subsequently verified via `php -l` (119 files) and the non-destructive regression test suite.

---

| Fix ID | Target File(s) | Exact Change Summary | Issue Resolved |
|---|---|---|---|
| **FIX-01** | `views/pages/finance_report_print.php`<br>`app/services/DashboardExportService.php` | Replaced `al.performed_by = u.id` with valid schema column `al.performed_by_id = u.id` in Chapel-scoped Staff Activity queries. | Fatal `Unknown column 'al.performed_by'` SQL exception on Chapel reports (AUD-01) |
| **FIX-02** | `app/controllers/InquiryController.php`<br>`app/models/Inquiry.php` | Restricted `handleRequest()` ownership check so branch users (`chapel_id > 0`) can only access exact matching `chapel_id` (not `null`), while Cathedral Staff (`empty(chapel_id)`) manage Cathedral (`'cathedral'`) inquiries. Updated `Inquiry::getAll`, `getArchived`, `getActiveCount`, `getArchivedCount`, and `getPendingCount` to remove `OR chapel_id IS NULL` from branch chapel queries and handle `'cathedral'` cleanly. | Cross-chapel access & badge leak of Mother Cathedral inquiries (AUD-02) |
| **FIX-03** | `app/controllers/InquiryController.php` | Guarded `fulfillMerchReservation()` against `status === 'Completed'` or `!empty($inq['is_archived'])` and prioritized `item_id` / `quantity` DB columns before regex fallback. | Double stock deduction on rapid double-click / replay (AUD-03) |
| **FIX-04** | `app/controllers/SacramentalController.php` | Replaced `$this->role === 'Chapel Admin'` check in `handleRequest()` and `processIntakeSave()` with `!in_array($this->role, ['Admin', 'Cathedral Admin'], true)` so Branch Staff cannot forge `scope=cathedral` or foreign `chapel_id`, and Cathedral Staff are pinned to Cathedral (`0`). | Branch Staff cross-chapel / Cathedral record injection bypass (AUD-04) |
| **FIX-05** | `app/controllers/DashboardController.php` | Removed `'Priest', 'Pastor'` from `$isGlobalBulletinAdmin` in `handleBulletinActions()`; updated `pending_inquiries` badge scope for Cathedral Staff to `'cathedral'`. | Priest cross-chapel bulletin edit/delete bypass & Staff badge leak (AUD-05) |
| **FIX-06** | `app/controllers/AdminController.php` | Added `$allowedRoles` whitelist (`Admin`, `Cathedral Admin`, `Chapel Admin`, `Staff`, `Priest`, `Member`) and active duplicate email check (`LOWER(TRIM(email))` where `status != 'rejected'`) in `handleUserActions()`. Added `parse_url(..., PHP_URL_SCHEME) === 'https'` + host check on `map_embed_url` in `handleParishInfoActions()`. | Arbitrary role assignment, duplicate active emails, & `javascript:` URL in Parish map embed (AUD-06) |
| **FIX-07** | `health_check.php` | Added `if (PHP_SAPI !== 'cli')` check requiring authenticated `'Admin'` session, returning `403 Forbidden` otherwise. | Unauthenticated public disclosure of diagnostics & server environment (AUD-07) |
| **FIX-08** | `app/services/DashboardExportService.php` | Scoped CSV Sections 1, 3, 9 (Cathedral merch store omitted when `$chapelId > 0`), 11 (`certificate_issuances` joined on `sacramental_records.chapel_id`), 12 (`tickets.chapel_id`), and 14 (`audit_logs` + `users.chapel_id`). | Cross-chapel & Cathedral store data leak in CSV exports (AUD-08) |
| **FIX-09** | `app/controllers/inbox_preview.php`<br>`assets/js/inbox-dropdown.js` | Enforced `POST` (`405` on GET) + CSRF validation (`$_POST['csrf']` / `X-CSRF-TOKEN`, `403` on failure) on `mark_read`, updated frontend `fetch()` caller in `inbox-dropdown.js`, and scoped Cathedral Staff (`role === 'Staff'` with empty `chapel_id`) to `'cathedral'`. | GET state change without CSRF & Cathedral Staff inquiry leak (AUD-09) |
| **FIX-10** | `app/controllers/FinanceController.php`<br>`app/controllers/ChatController.php`<br>`app/controllers/PortalController.php` | Added donation amount bounds, method whitelist (`Cash`, `GCash`, `Bank Transfer`, `Maya`, `Check`, `Other`), and string sanitization in `logDonation()`. Logged chat exceptions server-side instead of returning `$e->getMessage()` and added `canAccessRoom()` check in `ajaxMarkRead()`. Replaced raw `$_SERVER['PHP_SELF']` redirect in `PortalController` with `basename()` allowlist. | Input bounds gaps, exception message leak, unauthorized room cursor update, & unsafe redirect target (AUD-10) |
| **FIX-11** | `assets/js/dashboard-availability.js`<br>`assets/js/dashboard-profile.js`<br>`.dockerignore` | Added `escapeAvailHtml()` before `.innerHTML` interpolation of event titles/types/statuses and escaped uploaded filenames in `dashboard-profile.js`. Added `tests/`, `screenshots/`, `guest_*.html`, and `storage/rate_limits/*` to `.dockerignore`. | DOM `.innerHTML` XSS vectors & container image artifact hygiene (AUD-11) |
| **FIX-12** | `app/services/SacramentalReportingService.php` | Updated Baptism duplicate detection in `checkDuplicate()` to evaluate `YEAR(event_date)` using `event_date ?? date_of_birth` and accept `child_name ?? person_name` cleanly. | Missed cross-year infant Baptism duplicates & key fallback gap in `checkDuplicate()` |
